# Changelog

The changes to Ädelsten a user can notice, release by release. Versions follow Semantic Versioning, as the README's
*What a version number promises* says; a break of a versioned interface is marked **Breaking**, with the old and the
new call.

## 0.5.0 (2026-11-27)

The first release: a library of molecular integrals over Gaussian basis functions, callable from Rust, C, Fortran,
Python and Julia (the README lists what it computes). There is no earlier release to check compliance against. Before
1.0.0 its interfaces may still change in a minor release.
